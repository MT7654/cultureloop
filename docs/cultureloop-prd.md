# CultureLoop · approved build framing

CultureLoop connects a previous cultural outing to a personally relevant next Singapore experience. The supplied specification is the authoritative PRD; this is its concise local companion. Shared Page update pending because no Pages editing tool is exposed.

Audience: digitally comfortable Singapore Citizens with credits remaining, exploring alone or planning a social outing. Provisional motivation: the next experience lacks a compelling connection to the last. This is a hypothesis.

Confirmed flow: hook → last chapter (manual S$0–100 balance, category, sentiment, highlights) → cultural DNA (up to five tastes, occasion, informational timing) → three explainable recommendations and Culture Constellation → interpretive event preview with source/budget/save → My Loop saved collection. First-time and surprise routes, back navigation, reload persistence and recovery are required.

Priority: a polished end-to-end local prototype and honest data. Signature: selectable paths from known interests to actual curated event relationships. Familiar matches and an adjacent bridge use deterministic scoring. Audio is optional original synthesis, user initiated and labelled. Original vector artwork depicts moods, never actual performers.

Build: React, TypeScript, Vite, Tailwind, Motion, local JSON, localStorage, Web Audio, Vitest and browser checks. No backend, authentication, Singpass, checkout or inventory claims. Deployment prepared for Vercel. Publication only if authorised.

Demo: S$45 remaining after a musical on a date → indie/storytelling → constellation → surprising preview → saved next chapter. Research and actual checks are recorded separately. Participant testing, team identities and judge-accessible remote links remain pending.
