## Editorial metadata

`tags`, `occasions`, `bridgeFromTags` and `bridgeExplanations` are CultureLoop editorial interpretations of the listed artistic forms. They are not organiser endorsements or predictions of individual enjoyment. Bridge explanations connect an actual feature (e.g. spoken word, orchestra, character-led heritage) to a selected taste. Occasion labels describe a possible visiting context; age and admission restrictions still apply. We do not infer suitability from age, citizenship or demographic stereotypes.

No event images or audio were copied. Original abstract graphics and synthesised sound in the UI are artistic interpretations, not event photographs or recordings. Event names, dates, venues and prices remain attributed to linked sources.

## Deterministic recommendation rules

Eligibility first: verified status; source URL on an approved official/ticketing host; nonempty title, description and valid date range; event ends on/after today in **Asia/Singapore**; sold-out entries excluded. Past disliked category excluded unless user explicitly chooses an interest mapped to that category. Optional `dateFrom`/`dateTo` filter by verified range overlap. Weekday-evening/weekend preference is informational because complete session schedules are unavailable; never guess sessions.

Score components: interest overlap up to 30; prior category affinity up to 15; editorial occasion fit up to 15; estimated base-ticket budget fit up to 15; an explicitly authored cultural bridge up to 15; verified date proximity up to 10. Missing interests/past/price get neutral scores. Scores are local sorting aids, not percentages or scientific predictions. Category diversity retains a strongest match and a supported bridge, and adds another category where possible; a loved prior category is retained when available. `Surprise me` prioritises supported bridges. Ties break by stable event ID.

One-ticket estimate: credits applied = min(manual balance, base starting price); cash top-up = max(price − balance, 0). Unknown prices return null estimates, never zero. Balance clamps to S$0–100. Saving never changes credits. Price notes disclose tiers, fees and any known admission restrictions. No checkout, booking availability or attendance verification happens in CultureLoop.

Persistence uses versioned key `cultureloop:v1`; malformed or inaccessible localStorage falls back to a new in-memory profile. Saved fields are validated and capped. User titles are rendered as plain text; HTML delimiters/control characters are removed on hydration. No identifiers or analytics are collected.
